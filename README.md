# RefalABBrainfuck

Интерпретатор языка программирования [Brainfuck](https://ru.wikipedia.org/wiki/Brainfuck), написанный на языке программирования [РефалАБ](https://github.com/Aleksandr3Bocharov/refalab).

Программа "RefalABBrainfuck" интерпретирует код на языке Brainfuck из исходного файла.

## Особенности

- **Две версии программы:**
    - Консольная версия — классический интерпретатор с вводом/выводом через стандартные потоки;
    - GUI версия — графический интерфейс на основе библиотек [raylib](https://www.raylib.com/) и [raygui](https://github.com/raysan5/raygui);
- **Интерпретация из файла** — запуск Brainfuck-программ из исходных файлов;
- **Коллекция примеров** — классические Brainfuck-программы в папке `examples`;
- **Написан на РефалАБ** — демонстрация возможностей языка для реализации интерпретаторов.

## Системные требования

### РефалАБ
- **Версия:** 2.1 или выше
- **Переменные окружения:** должны быть настроены согласно документации РефалАБ
    - `REFALABBIN` — путь к исполняемым файлам РефалАБ;
    - `REFALABCFLAGS` — флаги компилятора C;
    - `REFALABINCLUDE` — путь к заголовочным файлам;
    - `REFALABLFLAGS` — флаги компоновщика.

Подробнее см. [документацию по установке РефалАБ](https://github.com/Aleksandr3Bocharov/refalab).

### Компилятор
- Компилятор C Clang

### Для GUI версии (дополнительно)

**raylib 5.5:**

- Windows:
    - Скачать [raylib 5.5 для Windows x64 (mingw-w64)](https://github.com/raysan5/raylib/releases/download/5.5/raylib-5.5_win64_mingw-w64.zip) или [raylib 5.5 для Windows x86 (mingw-w64)](https://github.com/raysan5/raylib/releases/download/5.5/raylib-5.5_win32_mingw-w64.zip);
    - Распаковать в любую директорию;
    - Отредактировать `make_run_gui.bat`, изменив путь в строке:

            set RAYLIB=F:\Programming\raylib-5.5_win64_mingw-w64
на свой путь к распакованному raylib.

- POSIX:
    - Установить через пакетный менеджер (например, `apt install libraylib-dev` для Ubuntu);
    - Скрипт сборки использует системные библиотеки.

**raygui:**
- Включён в исходный код проекта в директории `src/raygui/`;
- Дополнительная установка не требуется.

## Использование

### Консольная версия

**Сборка и запуск программы с указанием файла с Brainfuck-кодом:**

Windows:

    make_run.bat program.b

POSIX:

    ./make_run program.b

**Что происходит:**
1. Скрипт компилирует исходные файлы РефалАБ и C;
2. Создаёт исполняемый файл `bin/refalabbrainfuck`;
3. Запускает программу с указанным файлом.

**Требования:**
- Программа принимает ровно один аргумент — имя файла с Brainfuck-кодом;
- Файл должен существовать.

**Пример запуска (Windows):**

    make_run.bat examples\hello1.b

**Пример запуска (POSIX):**

    ./make_run examples/hello1.b

**Вывод программы:**

    Интерпретатор языка программирования Brainfuck на РефалАБ.
    
    Программа "RefalABBrainfuck" интерпретирует код на языке Brainfuck из исходного файла.
    
    Открытие исходного файла "examples/hello1.b" с кодом на языке программирования Brainfuck.
    
    Запуск интерпретатора кода на языке программирования Brainfuck.
    Hello World!

**Коды ошибок:**
- 9 — неправильный синтаксис командной строки;
- 19 — исходный файл не существует;
- 29 — ошибка открытия файла;
- 99 — синтаксические ошибки в Brainfuck-коде.

**Повторный запуск без компиляции:**

После первой сборки можно запускать программу напрямую:

Windows:

    bin\refalabbrainfuck.exe program.b

POSIX:

    ./bin/refalabbrainfuck program.b

Это быстрее, так как не требует перекомпиляции исходников.

### GUI версия

Сборка и запуск графической версии:

Windows:

    make_run_gui.bat

POSIX:

    ./make_run_gui

**Особенности GUI версии:**
- Графическое окно 1024×360 пикселей;
- Поддержка кириллицы (шрифт DejaVu);
- Частота обновления: 60 FPS.

**Управление:**
- Ctrl+O или кнопка "Открыть файл" — выбор файла с Brainfuck-кодом;
- Ctrl+R или кнопка "Запустить интерпретатор" — запуск интерпретации;
- Enter — подтверждение в диалогах;
- Escape — отмена в диалогах.

**Порядок работы:**
1. Запустить программу;
2. Нажать "Открыть файл" (Ctrl+O);
3. Выбрать файл с Brainfuck-кодом;
4. Нажать "Запустить интерпретатор" (Ctrl+R);
5. Просмотреть результаты выполнения.

**Обработка ошибок:**
- При синтаксических ошибках в коде открывается диалог со списком ошибок;
- Ошибки можно прокручивать стрелками вверх/вниз;
- Нажать "ОК" или Enter для закрытия диалога.

**Выход из программы:**
- При закрытии окна появляется диалог подтверждения выхода;
- Выбрать "Да" или нажать Enter для выхода;
- Выбрать "Нет" или Escape для продолжения работы.

**Повторный запуск без компиляции:**

После первой сборки можно запускать программу напрямую:

Windows:

    bin\refalabbrainfuck_gui.exe

POSIX:

    ./bin/refalabbrainfuck_gui

## Команды Brainfuck

| Команда | Описание |
| :---: | :--- |
| **`>`** | Переместить указатель памяти вправо |
| **`<`** | Переместить указатель памяти влево |
| **`+`** | Увеличить значение в текущей ячейке |
| **`-`** | Уменьшить значение в текущей ячейке |
| **`.`** | Вывести символ из текущей ячейки |
| **`,`** | Ввести символ в текущую ячейку |
| **`[`** | Начать цикл (выполнять, пока значение не равно 0) |
| **`]`** | Конец цикла |

## Примеры программ

В папке `examples` находятся классические Brainfuck-программы:

**Hello World (hello1.b — hello5.b)**

Пять различных вариантов классической программы "Hello, World!", демонстрирующих разные подходы к выводу текста.

**Cat (cat.b)**

    ,[.,]

Простейшая программа-эхо: читает символы со стандартного ввода и выводит их обратно, пока не встретит конец файла.

**Определение размера ячейки (cell_size.b)**

Тестовая программа, определяющая размер ячейки памяти интерпретатора (8, 16 или 32 бита). Проверяет поведение при переполнении и выводит результат.

**Quine (quine.b)**

Программа, выводящая свой собственный исходный код — классический пример самовоспроизводящейся программы.

**Счётчик с циклами (looping_counter.b)**

Программа, демонстрирующая работу вложенных циклов и вывод последовательности символов.

**Тестовые программы (test.b, test_fail.b)**

Программы для тестирования корректности работы интерпретатора, включая проверку обработки ошибок.
